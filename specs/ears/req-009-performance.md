# req-009-performance: パフォーマンス・SEO（非機能要件）

## 概要

SSR キャッシュ戦略、動的メタデータ生成、ビューポート・フォント設定に関する非機能要件。

---

## 要件一覧

### 常時型 (Ubiquitous)

- **req-009-001**: システムは、検索 API レスポンスを 30 秒間 ISR キャッシュしなければならない（`next: { revalidate: 30 }`）
- **req-009-002**: システムは、リポジトリ詳細 API レスポンスを 60 秒間 ISR キャッシュしなければならない（`next: { revalidate: 60 }`）
- **req-009-003**: システムは、`robots: { index: false }` を設定し検索エンジンのインデックスを抑制しなければならない
- **req-009-004**: システムは、`viewport` メタタグ（device-width, initial-scale=1）を設定し、モバイルの表示スケールを正しく制御しなければならない
- **req-009-005**: システムは、Noto Sans JP フォントを `display: swap` で読み込み、レイアウトシフト（CLS）を最小化しなければならない

### イベント駆動型 (Event-driven) — WHEN

- **req-009-006**: 検索キーワードが指定されたとき、システムは `<title>「{keyword}」の検索結果 | GitHub リポジトリ検索</title>` を動的生成しなければならない

### オプション型 (Optional) — WHERE

- **req-009-007**: 検索キーワードが未指定の場合、システムは `<title>GitHub リポジトリ検索</title>` をデフォルトタイトルとして表示しなければならない
