# req-007-sort: 検索結果のソート

## 概要

検索結果を「関連度・Star数・Fork数・更新日」でソートする機能。

---

## 要件一覧

### 常時型 (Ubiquitous)

- **req-007-001**: システムは、ソートオプション（関連度・Star数・Fork数・更新日）を URL の `sort` パラメータで管理しなければならない
- **req-007-002**: システムは、`sort` パラメータのデフォルト値を「関連度（best match）」としなければならない
- **req-007-003**: システムは、ソートセレクタを検索結果一覧のヘッダー領域に表示しなければならない

### イベント駆動型 (Event-driven) — WHEN

- **req-007-004**: ユーザーがソートオプションを変更したとき、システムは URL の `sort` パラメータを更新し検索結果を再取得しなければならない
- **req-007-005**: ユーザーがソートオプションを変更したとき、システムは `page` パラメータを 1 にリセットしなければならない

### オプション型 (Optional) — WHERE

- **req-007-006**: URL に `sort` パラメータが存在する場合、システムは初期表示時にそのソート条件で検索を実行しなければならない

### 望ましくない動作型 (Unwanted Behavior) — IF

- **req-007-007**: `sort` パラメータが不正な値の場合、システムは「関連度（best match）」にフォールバックしなければならない
