# req-003-detail: リポジトリ詳細

## 概要

選択したリポジトリの詳細情報を表示する機能。

---

## 要件一覧

### 常時型 (Ubiquitous)

- **req-003-001**: システムは、リポジトリ詳細ページを `/repos/{owner}/{repo}` のパスで提供しなければならない
- **req-003-002**: システムは、リポジトリ詳細ページを async Server Component として SSR で描画しなければならない
- **req-003-003**: システムは、リポジトリ詳細ページにリポジトリ名・オーナー名・説明文・スター数・フォーク数・オープンイシュー数・プログラミング言語・ライセンス・最終更新日・GitHub URL を表示しなければならない
- **req-003-004**: システムは、リポジトリ詳細ページに検索結果一覧へ戻るリンクを表示しなければならない

### イベント駆動型 (Event-driven) — WHEN

- **req-003-005**: ユーザーが「GitHubで見る」リンクをクリックしたとき、システムは GitHub のリポジトリページを新しいタブで開かなければならない
- **req-003-006**: ユーザーが「戻る」リンクをクリックしたとき、システムは直前の検索結果一覧ページへ戻らなければならない

### 状態駆動型 (State-driven) — WHILE

- **req-003-007**: リポジトリ詳細取得中の間、システムは Suspense フォールバックとしてスケルトン UI を表示しなければならない

### 望ましくない動作型 (Unwanted Behavior) — IF

- **req-003-008**: リポジトリに説明文がないなら、システムは「説明なし」と表示しなければならない
- **req-003-009**: リポジトリにライセンスが設定されていないなら、システムは「ライセンスなし」と表示しなければならない
- **req-003-010**: 存在しないリポジトリの詳細ページにアクセスされたなら、システムは404ページを表示しなければならない
- **req-003-011**: 外部リンクを新しいタブで開くなら、システムは `rel="noopener noreferrer"` を付与しなければならない
