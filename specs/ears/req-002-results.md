# req-002-results: 検索結果一覧

## 概要

GitHub リポジトリの検索結果を一覧表示する機能。

---

## 要件一覧

### 常時型 (Ubiquitous)

- **req-002-001**: システムは、検索結果を async Server Component として SSR で描画しなければならない
- **req-002-002**: システムは、各リポジトリカードにリポジトリ名・オーナー名・スター数・フォーク数・言語・説明文を表示しなければならない
- **req-002-003**: システムは、検索結果の総件数を表示しなければならない
- **req-002-004**: システムは、1ページあたり50件のリポジトリを表示しなければならない

### イベント駆動型 (Event-driven) — WHEN

- **req-002-005**: 検索が完了したとき、システムは検索結果の一覧を表示しなければならない
- **req-002-006**: ユーザーがリポジトリカードをクリックしたとき、システムはリポジトリ詳細ページへ遷移しなければならない

### 状態駆動型 (State-driven) — WHILE

- **req-002-007**: 検索結果取得中の間、システムは Suspense フォールバックとしてスケルトン UI を表示しなければならない

### 望ましくない動作型 (Unwanted Behavior) — IF

- **req-002-008**: 検索結果が0件なら、システムは「該当するリポジトリが見つかりませんでした」というメッセージを表示しなければならない
- **req-002-009**: 検索結果をクライアント側でフェッチしようとするなら、システムは Server Component での取得に切り替えなければならない

### オプション型 (Optional) — WHERE

- **req-002-010**: `q` パラメータが未指定の場合、システムは検索結果エリアを表示せず、検索フォームのみを表示しなければならない
